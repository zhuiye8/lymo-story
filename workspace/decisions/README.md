# Decisions

本目录只存放绑定执行的 PM/监督决策。工程师方案、调研结论、个人建议不能放在这里，除非已经被批准。

## 决策文件必须回答

1. 决定了什么？
2. 为什么这样决定？
3. 影响哪些阶段或模块？
4. 哪些选项被拒绝？
5. 何时需要重新评估？

## 命名

```text
YYYY-MM-DD-<topic>.md
```

示例：

- `2026-04-26-rearchitecture-approval.md`
- `2026-04-27-phase-0-scope.md`
- `2026-04-27-graph-memory-choice.md`
